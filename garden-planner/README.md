# מתכנן גינות מקצועי

אתר סטטי לתכנון גינות בשרטוט דו ממדי:

- התחלה ממשטח ריק עם מידות מגרש במטרים.
- הוספת פריטים בלחיצה על אזור בשרטוט.
- בחירה מתוך רשימה סגורה: בטון, דשא, גדר חיה, עצים, ערוגות, שבילים, דק, פרגולה, גדר ונקודות מים קיימות.
- קביעת רוחב/עומק במטרים לכל פריט.
- הצמדת פריט חדש לפריט נבחר באחד מארבעת הצדדים.
- סימון כמה נקודות מים קיימות.
- סיכום שטחים, חפיפות לבדיקה וייצוא JSON.
- שמירה אוטומטית בדפדפן באמצעות `localStorage`.

## הפעלה מקומית

```bash
cd garden-planner
python3 -m http.server 8080
```

פתחו בדפדפן: `http://localhost:8080`
